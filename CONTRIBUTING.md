# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for taking the time to contribute! This guide explains how you can help improve this project.

## Ways to Contribute

- **Report bugs** – open an issue describing the problem
- **Fix bugs** – pick an open issue and submit a pull request
- **Improve documentation** – fix typos, clarify explanations or add examples to the README
- **Suggest enhancements** – propose new features such as compound interest or input validation improvements
- **Share ideas** – start a discussion in an issue

## Reporting Bugs

When opening a bug report, please include:

1. A clear and descriptive title
2. Steps to reproduce the problem
3. The input values you used (principal, rate, time)
4. The expected result and the actual result
5. Your Python version and operating system

## Submitting Changes

1. Fork this repository
2. Create a new branch for your change:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes and test them:
   ```bash
   python simple_interest.py
   ```
4. Commit with a clear message:
   ```bash
   git commit -m "Add: short description of the change"
   ```
5. Push your branch and open a Pull Request against `main`
6. Describe what you changed and why in the Pull Request

## Coding Guidelines

- Follow [PEP 8](https://peps.python.org/pep-0008/) style for Python code
- Use meaningful variable and function names
- Add docstrings and comments where they help understanding
- Keep functions small and focused on one task
